# Spec - Delete Functionality

## Scenarios

### Scenario 1: 删除文件夹
- GIVEN: 用户在工具分享页面
- WHEN: 用户点击文件夹的删除按钮
- THEN: 弹出确认对话框，显示"确定删除该文件夹吗？"

### Scenario 2: 确认删除空文件夹
- GIVEN: 用户点击了文件夹的删除按钮，确认对话框已显示
- WHEN: 用户点击"确定"
- THEN: 系统删除该文件夹，刷新文件夹列表，显示成功提示

### Scenario 3: 取消删除文件夹
- GIVEN: 用户点击了文件夹的删除按钮，确认对话框已显示
- WHEN: 用户点击"取消"
- THEN: 对话框关闭，文件夹未被删除

### Scenario 4: 删除有文件的文件夹
- GIVEN: 用户尝试删除一个包含文件的文件夹
- WHEN: 用户确认删除
- THEN: 系统拒绝删除，显示错误提示"请先删除文件夹内的文件"

### Scenario 5: 删除文件
- GIVEN: 用户在工具分享页面，文件列表已显示
- WHEN: 用户点击某个文件的删除按钮
- THEN: 弹出确认对话框，显示"确定删除该文件吗？"

### Scenario 6: 确认删除文件
- GIVEN: 用户点击了文件的删除按钮，确认对话框已显示
- WHEN: 用户点击"确定"
- THEN: 系统删除文件记录和存储文件，刷新文件列表，显示成功提示

### Scenario 7: 取消删除文件
- GIVEN: 用户点击了文件的删除按钮，确认对话框已显示
- WHEN: 用户点击"取消"
- THEN: 对话框关闭，文件未被删除

### Scenario 8: 删除成功后刷新列表
- GIVEN: 用户成功删除了文件夹或文件
- WHEN: 删除操作完成
- THEN: 对应的列表自动刷新，删除的项目不再显示
