# Proposal

## Problem

当前工具分享功能存在以下体验问题：
1. 文件夹结构不清晰：文件夹可以嵌套子文件夹，导致用户界面复杂，操作繁琐
2. 缺少删除功能：用户无法删除已创建的文件夹或文件
3. 文件排序不合理：文件列表按默认顺序排列，用户难以找到热门文件

## Testable Behaviors

### 文件夹点击行为
- WHEN 用户点击左侧文件夹 THEN 右侧文件列表展示该文件夹内的所有文件
- WHEN 用户进入文件夹后点击"返回上级" THEN 返回到根目录列表
- WHEN 文件夹为空 THEN 显示"暂无文件"提示

### 删除功能
- WHEN 用户点击文件夹的删除按钮 THEN 弹出确认对话框
- WHEN 用户确认删除文件夹 THEN 系统删除文件夹并刷新列表
- WHEN 用户点击文件的删除按钮 THEN 弹出确认对话框
- WHEN 用户确认删除文件 THEN 系统删除文件记录和存储文件并刷新列表
- WHEN 删除有文件的文件夹 THEN 提示"请先删除文件夹内的文件"

### 文件排序
- WHEN 用户打开工具分享页面或进入文件夹 THEN 文件列表按下载量从高到低排序
- WHEN 用户点击文件列表的标题行 THEN 当前排序不变（下载量降序）

## Acceptance Criteria

1. 左侧只显示顶级文件夹，点击文件夹后右侧显示该文件夹内的文件列表
2. 文件夹和文件都支持删除操作，带确认对话框
3. 文件列表默认按下载量（downloadCount）降序排列
4. 删除成功后显示成功提示，失败显示错误原因
