# Proposal

## Problem

当前登录页面只提供登录功能，用户无法自行注册账号。当需要新增用户时，必须由管理员手动创建。为了提升用户体验和系统的自服务能力，需要在登录页面增加"注册"入口，允许用户自主提交注册申请。

## Testable Behaviors

- WHEN 登录页面加载 THEN 显示"注册账号"链接或按钮
- WHEN 用户点击"注册账号"链接 THEN 跳转到注册页面 `/register`
- WHEN 用户在注册页面填写信息后点击提交 THEN 系统创建注册申请并显示提交成功提示
- WHEN 注册申请提交成功 THEN 页面提示"注册申请已提交，请等待管理员审批"

## Acceptance Criteria

1. 登录页面显示"注册账号"入口，位置明显（建议在登录按钮下方）
2. 点击"注册账号"跳转到 `/register` 页面
3. 注册页面包含：用户名、密码、确认密码、手机号（可选）等字段
4. 注册表单校验：密码与确认密码一致、密码复杂度符合要求
5. 注册提交后显示审批提示，不直接登录
