# Proposal

## Problem

当前登录页面只有密码输入框（用户名固定为 admin），无法满足用户自定义登录的需求。同时左侧导航包含"租户信息认证"、"节点管理"、"网络参数管理"三个业务模块，这些功能已被废弃或不再使用，需要从导航中移除。此外，系统需要新增"知识库"入口，方便用户快速访问 AI 知识库问答功能。

## Testable Behaviors

- WHEN 登录页面加载 THEN 用户名输入框可见且可输入
- WHEN 用户输入用户名和密码后点击登录 THEN 系统使用用户输入的用户名进行认证
- WHEN 用户未输入用户名点击登录 THEN 前端表单验证提示用户名不能为空
- WHEN 左侧导航渲染 THEN 不显示"租户信息认证"菜单项
- WHEN 左侧导航渲染 THEN 不显示"节点管理"菜单项
- WHEN 左侧导航渲染 THEN 不显示"网络参数管理"菜单项
- WHEN 左侧导航渲染 THEN 显示"知识库"菜单项
- WHEN 用户点击知识库菜单 THEN 跳转到知识库页面 /knowledge
- WHEN 用户访问 /knowledge 路径 THEN 显示知识库问答界面

## Acceptance Criteria

1. 登录页面包含用户名输入框，默认值清空，用户可自行输入
2. 左导航中移除"租户信息认证"、"节点管理"、"网络参数管理"三个菜单项及其对应代码
3. 左导航中新增"知识库"菜单项，图标为 `el-icon-document`，点击跳转至 /knowledge
4. 知识库页面作为独立页面存在，包含问答输入框和历史记录展示区域
