# Proposal

## Problem

当前系统存在三个 UI 问题需要修复：
1. 左导航菜单缺少图标显示，影响用户体验和视觉识别
2. 工具分享页面创建文件夹功能失败，用户无法创建文件夹
3. 工具分享页面的按钮名称不是中文，影响中文用户的使用

## Testable Behaviors

### 导航菜单图标问题
- WHEN 用户进入前端页面 THEN 左导航菜单的每一项都显示对应的图标
- WHEN 导航菜单有子菜单 THEN 父级菜单显示展开/收起图标

### 工具分享页面创建文件夹问题
- WHEN 用户在工具分享页面点击"创建文件夹"按钮 THEN 系统创建新文件夹并显示在列表中
- WHEN 用户在工具分享页面点击"新建文件"按钮 THEN 系统创建新文件并显示在列表中
- WHEN 创建文件夹/文件成功后 THEN 显示成功提示

### 工具分享页面按钮中文问题
- WHEN 用户打开工具分享页面 THEN 所有按钮名称显示为中文
- WHEN 用户点击"新建"相关按钮 THEN 按钮文字为中文

## Acceptance Criteria

1. 左导航菜单所有菜单项均正确显示图标（el-icon 或自定义 icon）
2. 工具分享页面可以成功创建文件夹和文件
3. 工具分享页面的所有按钮名称均为中文
4. 修复后前端无 lint 错误，可以正常构建
