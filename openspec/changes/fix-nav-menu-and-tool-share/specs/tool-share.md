# Spec - Tool Share Page

## Scenarios

### Scenario 1: 创建文件夹成功
- GIVEN: 用户在工具分享页面
- WHEN: 用户点击"创建文件夹"按钮，输入文件夹名称后点击确定
- THEN: 系统创建新文件夹并在文件夹列表中显示
- AND: 显示成功提示消息"创建文件夹成功"

### Scenario 2: 创建文件夹名称为空
- GIVEN: 用户在工具分享页面的创建文件夹对话框
- WHEN: 用户未输入文件夹名称就点击确定
- THEN: 显示警告消息"请输入文件夹名称"
- AND: 不创建文件夹

### Scenario 3: 创建根目录文件夹
- GIVEN: 用户在工具分享页面的根目录
- WHEN: 用户创建新文件夹（不进入任何子文件夹）
- THEN: 文件夹创建在根目录（parentId 为 null）

### Scenario 4: 创建子文件夹
- GIVEN: 用户已进入某个子文件夹
- WHEN: 用户创建新文件夹
- THEN: 文件夹创建在该子文件夹内（parentId 指向当前文件夹）

### Scenario 5: 按钮名称显示为中文
- GIVEN: 用户使用中文界面
- WHEN: 用户打开工具分享页面
- THEN: 所有按钮名称显示为中文（"创建文件夹"、"上传文件"、"返回上级"等）

### Scenario 6: 上传文件成功
- GIVEN: 用户在工具分享页面
- WHEN: 用户点击"上传文件"按钮，选择文件，填写工具名称后点击确定
- THEN: 系统上传文件并在文件列表中显示
- AND: 显示成功提示消息"上传成功"
